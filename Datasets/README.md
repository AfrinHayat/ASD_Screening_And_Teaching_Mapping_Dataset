## Dataset Description

This repository includes three mapping datasets designed to connect Autism Spectrum Disorder (ASD) screening attributes to targeted skill deficiencies and corresponding educational interventions:

- Mapping (Education and ASD on Targeted Skill) Toddler.csv  
- Mapping (Education and ASD on Targeted Skill) Children.csv  
- Mapping (Education and ASD on Targeted Skill) Adolescent.csv  

These datasets are constructed using screening instruments:
- Q-CHAT-10 for toddlers  
- AQ-10 for children and adolescents
